	\section*{Session 11.1: \\ Quadratic Formula, Discriminant, Number of Solutions}

		\subsection*{The Quadratic Formula}

			For any quadratic equation in standard form $ax^2 + bx + c = 0$ where $a \neq 0$:

			$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

			This formula gives you the solutions (roots) of the equation.

		\subsection*{Using the Quadratic Formula}

			\textbf{Steps:}
			\begin{enumerate}
				\item Write the equation in standard form: $ax^2 + bx + c = 0$
				\item Identify $a$, $b$, and $c$
				\item Substitute into the formula
				\item Simplify under the square root first
				\item Simplify the entire expression
				\item Write two solutions using the $\pm$ symbol
			\end{enumerate}

		\subsection*{The Discriminant}

			The discriminant is the expression under the square root: $b^2 - 4ac$

			The discriminant tells you how many real solutions the equation has:

			\textbf{If $b^2 - 4ac > 0$:} Two different real solutions

			\textbf{If $b^2 - 4ac = 0$:} One real solution (a repeated root)

			\textbf{If $b^2 - 4ac < 0$:} No real solutions (two complex solutions)

		\subsection*{Simplifying Square Roots}

			Remember to simplify radicals in your final answer.

			If you have a common factor in the numerator, factor it out.

	\section*{Session 11.2: \\ Applications: Projectile/Area Models}

		\subsection*{Projectile Motion}

			When an object is thrown or launched, its height $h$ (in feet) after $t$ seconds is modeled by:

			$$h = -16t^2 + v_0 t + h_0$$

			where:
			\begin{itemize}
				\item $-16$ is half the acceleration due to gravity (in $\text{ft}/\text{s}^2$)
				\item $v_0$ is the initial velocity (in ft/s)
				\item $h_0$ is the initial height (in feet)
			\end{itemize}

			\textbf{Important questions:}
			\begin{itemize}
				\item When does the object hit the ground? (Set $h = 0$)
				\item What is the maximum height? (Find the vertex)
				\item When does it reach a certain height? (Set $h =$ that height)
			\end{itemize}

		\subsection*{Area Problems}

			Many geometry problems involve quadratic equations:
			\begin{itemize}
				\item Rectangle: $\text{Area} = \text{length} \times \text{width}$
				\item Square: $\text{Area} = \text{side}^2$
				\item Triangle: $\text{Area} = \frac{1}{2} \times \text{base} \times \text{height}$
			\end{itemize}

		\subsection*{Checking Reasonableness}

			Always check if your answer makes sense in context:
			\begin{itemize}
				\item Time cannot be negative (usually)
				\item Lengths and distances must be positive
				\item Check units match the problem
				\item Does the magnitude make sense?
			\end{itemize}

	\section*{Session 11.3: \\ Mixed Methods: Choose Factor, Square Root, Formula}


		\subsection*{Three Methods for Solving Quadratics}

			\textbf{Method 1: Factoring}

			Best when: The quadratic factors easily

			Pros: Fast and simple when it works

			Cons: Doesn't always work; can be hard to see factors

			\vspace{0.5cm}

			\textbf{Method 2: Square Roots}

			Best when: Equation is in the form $(x - h)^2 = k$ or $ax^2 + c = 0$

			Pros: Very fast for these special forms

			Cons: Only works for specific types of equations

			\vspace{0.5cm}

			\textbf{Method 3: Quadratic Formula}

			Best when: Factoring is difficult or impossible

			Formula: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

			Pros: Always works for any quadratic

			Cons: More steps; arithmetic can be messy
            
            \vspace{0.5cm}

		\subsection*{Decision Guide}

			If it in the form $ax^2 + c = 0$ or $(x - h)^2 = k$
			$\rightarrow$ Use square roots

			\vspace{0.5cm}

			If you can easily see factors
            $\rightarrow$ Use factoring

			\vspace{0.5cm}

			If factoring is hard or you're unsure
			$\rightarrow$ Use the quadratic formula
